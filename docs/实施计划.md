# AI 任务完成提醒工具 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude 桌面 App 与 Codex 桌面 App 在"一轮跑完"或"等批准"时，经飞书群机器人把提醒推到 iPhone。

**Architecture:** 两个工具的官方钩子都调用同一个脚本 `task_reminder.py`。脚本在钩子里只做判断并立刻返回，真正的发送、重试、延时补查交给脱离钩子的后台子进程。另有 `install_hooks.py` 负责往两个工具的钩子配置里加减条目，由两个 `.command` 文件双击调用。

**Tech Stack:** 系统自带 Python 3.9.6，只用标准库（`json` `configparser` `urllib` `subprocess` `unittest`）；macOS 的 `ioreg` 与 `osascript`。

**Spec:** `docs/SPEC.md`（执行者须同时阅读）

## Global Constraints

- 只用 Python 3.9 标准库，不安装任何依赖；测试用 `unittest`，不用 pytest。
- 代码用普通函数，不用类（异常类除外），不做抽象层；注释、报错信息、日志一律中文。
- 命名不用 data / temp / helper / util / manager / do / process / handle。
- 不允许 `try: ... except: pass`；只捕获知道怎么处理的异常；报错信息带上导致出错的具体值。
- 不修改 `~/.codex/config.toml`。
- 钩子脚本不向标准输出打印任何内容，退出码恒为 0（出错走日志 + Mac 弹窗），不返回允许 / 拒绝决定。
- 钩子调用必须立刻返回：网络请求与等待只出现在后台子进程里。
- 飞书请求绕过代理直连；只连接飞书机器人地址。
- 安装目录 `~/开发/AI任务完成提醒/`，路径含中文，钩子命令里必须加引号。
- 默认值：任务时长门槛 120 秒，离开门槛 180 秒，摘要 100 字，重试共 3 次、间隔 5 秒，日志超过 1 MB 清空重写。
- 修改用户配置文件前先看内容并备份（`<原文件名>.bak-提醒工具-<日期>`）。

## Review Focus

1. **安装目录含中文和空格**：钩子命令被 shell 拆开导致脚本找不到。期望：任意含中文、空格的路径都能正确调用。（任务 5）
2. **钩子给的字段缺失或为 null**（如 `last_assistant_message` 为 null、没有 `tool_input.command`）。期望：照常发提醒，只是不带摘要，不崩。（任务 2、4）
3. **没有开始时间记录**（安装前就已开始的会话）。期望：只按"是否在电脑前"判断，消息里不写用时，不崩。（任务 2、4）
4. **配置里已有别人的钩子，或重复双击安装**。期望：别人的条目一条不少，自己的不重复添加。（任务 5）
5. **摘要含换行、Markdown 符号或超长**。期望：压成一行并截断到摘要字数，摘要字数为 0 时不带摘要。（任务 2）

### Task 4: 钩子入口与后台发送

**Files:**
- Modify: `task_reminder.py`、`tests/test_task_reminder.py`

**Interfaces:**
- Consumes: 任务 1–3 的全部函数。
- Produces（命令行）:
  - `python3 task_reminder.py <claude|codex> <turn-start|turn-end|needs-approval>`，标准输入为钩子 JSON。
  - `python3 task_reminder.py deliver <json 字符串>`：后台子进程入口。JSON 键：`text`、`recheck_after_seconds`（0 表示立即发）。
- Produces（函数）:
  - `summary_source_from_hook(event_kind: str, hook_input: dict) -> Optional[str]`：`turn-end` 取 `last_assistant_message`；`needs-approval` 依次取 `tool_input.command`、`message`、`tool_name`，都没有返回 `None`。
  - `decide_delivery(event_kind: str, elapsed_seconds: Optional[float], idle_seconds: float, settings: dict) -> Optional[int]`：返回 `0` 表示立即发；返回正整数表示多少秒后补查；返回 `None` 表示不发。规则：`should_notify` 为真 → `0`；否则 `needs-approval` → `settings["idle_seconds_threshold"]`；否则 `None`。
  - `start_background_delivery(text: str, recheck_after_seconds: int) -> None`：`subprocess.Popen([sys.executable, 本脚本, "deliver", json], start_new_session=True, stdin/stdout/stderr=DEVNULL)`，不等待。
  - `deliver(text: str, recheck_after_seconds: int) -> None`：若 `recheck_after_seconds > 0`，先 `time.sleep` 这么久，然后只有当 `keyboard_mouse_idle_seconds() >= recheck_after_seconds` 时才发；发送用 `send_with_retry`。
  - `main(argv: list, stdin_text: str) -> int`：恒返回 0。`turn-start` 只记开始时间。标准输入不是合法 JSON、缺 `session_id` 或 `cwd`、配置读取失败时：写日志 + `show_mac_alert`（信息含具体原因），返回 0。

**Files:**
- Create: `install_hooks.py`、`tests/test_install_hooks.py`、`安装.command`、`卸载.command`

**Interfaces（Produces）:**
- `validate_webhook_url(url: str) -> str`：去掉首尾空白后，必须以 `https://open.feishu.cn/open-apis/bot/v2/hook/` 或 `https://open.larksuite.com/open-apis/bot/v2/hook/` 开头且后面非空，否则抛 `ValueError`，信息含收到的值。
- `reminder_hook_command(script_path: str, tool: str, event_kind: str) -> str`：返回 `/usr/bin/python3 '<script_path>' <tool> <event_kind>`（路径用 `shlex.quote`）。
- `add_reminder_hooks(hooks_config: dict, tool: str, script_path: str) -> dict`：返回新字典，不改入参。事件对应关系（以任务 0 实测为准，如有出入先改这里）：
  - 两个工具：`UserPromptSubmit`→`turn-start`，`Stop`→`turn-end`，`PermissionRequest`→`needs-approval`
  - 仅 `claude`：`Notification`（匹配条件用任务 0 记下的"提问"类型值）→`needs-approval`
  - 已存在命令里含 `task_reminder.py` 的条目时先删再加，保证不重复。
- `remove_reminder_hooks(hooks_config: dict) -> dict`：删掉所有命令里含 `task_reminder.py` 的条目；因此变空的事件键一并删除；其他条目原样保留。
- `write_settings_file(ini_path: str, webhook_url: str) -> None`：按任务 1 的键名生成带中文注释的 `配置.ini`，默认 120 / 180 / 100，权限 `0o600`。已存在时只更新机器人地址，保留用户改过的数字。
- 命令行：`python3 install_hooks.py install` / `uninstall`。
  - `install`：提示粘贴机器人地址（并说明飞书群里添加自定义机器人、安全设置选"自定义关键词"填 `Claude` 和 `Codex`）→ 校验 → 写 `配置.ini` → 发一条"✅ Claude Code / Codex 提醒工具安装测试"并要求用户确认手机收到 → 备份并改 `~/.claude/settings.json` 的 `hooks` 与 `~/.codex/hooks.json`（文件不存在则新建）→ 用中文提示去 Codex"设置 → Hooks"点信任。测试消息发不出去时停止，不改任何钩子配置。
  - `uninstall`：备份后对两处配置调用 `remove_reminder_hooks` 并写回；`配置.ini` 与日志保留，提示用户可自行删除整个文件夹。
- `安装.command` / `卸载.command`：`cd "$(dirname "$0")" && /usr/bin/python3 install_hooks.py install`（或 `uninstall`），末尾 `read` 等回车再关窗口；两个文件需 `chmod +x`。
